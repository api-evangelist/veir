# VEIR

> VEIR is a superconducting power delivery company founded in 2019 and headquartered in Woburn,
> Massachusetts. It builds low- and medium-voltage high-temperature superconducting (HTS) transmission
> systems that carry 5-10x more power than conventional conductors at the same voltage, with roughly 90%
> less resistive line loss, aimed at AI data center campuses, energy producers and utilities. VEIR
> publishes no product API and no developer program. It does publish a deliberate agent-facing content
> layer: a markdown twin of every indexed page, a semantic index at /sitemap.md, an RFC 9727 API catalog,
> OIDC and OAuth protected-resource discovery documents, and a Content-Signal AI usage preference.

This file was generated by API Evangelist from VEIR's own public surface on 2026-08-05. VEIR does not
publish an /llms.txt of its own (probed 2026-08-05, HTTP 404). VEIR's own agent index is /sitemap.md.
